# Create Draft Pull Request

Use use_skill with name create-pr for repository inspection, checks, and PR preparation. With an installed authenticated gh CLI, use run_command with gh pr create --draft and --body-file for a multiline description. Confirm draft status and return the resulting URL. If remote access is unavailable, prepare the PR text and explain the blocker. Do not imply that Asrār has a GitHub MCP or session toolbar.
